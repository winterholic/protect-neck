# 목 건강 지킴이 (Protect Neck) 기획서

상태: 개정판 · 최종 수정: 2026-10-28 · 이전판: `protect-neck-planning.md`(PyQt5, Windows 전용)

## 1. 문제

하루 종일 모니터 앞에 앉아 있으면 머리가 점점 앞으로 나가고 어깨가 말린다. 알고는 있어도 집중하다 보면 한두 시간이 그냥 지나가서, 누가 끊어 주지 않으면 스트레칭을 하지 않는다.

1판을 만들어 놓고 결국 안 쓰게 된 이유는 기능이 없어서가 아니라 쓰기 불편해서였다. 실제로 걸렸던 점은 다음과 같다.

| 1판에서 걸린 점 | 왜 문제였나 |
| :-- | :-- |
| 회의 중이든 아니든 30분이 되면 창이 튀어나온다 | 미룰 방법이 「나중에 하기」(30분 통째 재시작)뿐이라, 결국 앱을 꺼 버리게 된다 |
| 자리를 비워도 타이머가 계속 돈다 | 점심 먹고 오면 바로 알림이 뜬다. 이미 쉬고 왔는데도 |
| 스트레칭 내용이 실제 동작과 안 맞는다 | 「턱 당기기 10회」를 15초에 하라고 하고, 그림은 정면 차렷 자세라 뭘 하라는 건지 안 보인다. 「목을 젖혀」처럼 거북목에 권하지 않는 동작도 섞여 있었다 |
| 스트레칭 도중 멈추거나 넘기거나 그만둘 수 없다 | 전화가 오면 그냥 창을 닫아야 했다 |
| 30분 고정, 설정·통계 탭은 기획에만 있다 | 사람마다 맞는 주기가 다르다 |
| 출퇴근 개념이 없다 | 아침마다 「시작하기」를 눌러야 하고, 퇴근 뒤 집에서 컴퓨터를 켜도 알림이 뜬다 |
| Windows 전용 (PyQt5 + PyInstaller) | 맥에서 쓸 수 없다 |
| 이미지 8장이 장당 5MB, 생성 도구 워터마크까지 들어가 있다 | 레포가 83MB가 되고 화면 품질도 떨어진다 |

## 2. 누구를 위한 앱인가

장시간 앉아서 일하는 사람. 1차 사용자는 만든 사람 본인이고, 맥과 윈도우를 둘 다 쓴다. 이 사람은 알림을 싫어한다. 그래서 이 앱의 핵심은 **끊어 주되, 짜증 나지 않게** 끊는 것이다.

## 3. 성공 기준

개인용 앱이라 거창한 지표는 없다. 아래 두 가지로 판단한다.

- **2주 동안 앱을 끄지 않고 켜 둔다.** 1판은 이 기준을 못 넘었다.
- **알림이 뜬 횟수 중 스트레칭(빠른 루틴 포함)이나 자리 비움으로 이어진 비율이 50% 이상.** 앱의 오늘 통계(완료·건너뜀·미룸 횟수)로 확인한다.

## 4. 이번에 하지 않는 것

- 계정, 서버, 기기 간 동기화. 데이터는 그 컴퓨터에만 저장한다.
- 웹캠으로 자세 감지. 정확도도 낮고 사생활 문제가 크다.
- 루틴 편집기. 루틴은 앱에 두 개(기본·빠른)만 넣어 둔다.
- 주간·월간 통계 화면. 오늘 숫자만 보여준다.
- 자동 업데이트, 코드 서명. 개인 배포라 생략한다. (맥에서 처음 열 때 「확인되지 않은 개발자」 경고가 뜬다.)

## 5. 해법 개요

Electron 앱 하나로 맥(메뉴 막대)과 윈도우(시스템 트레이)를 함께 지원한다. 타이머는 창이 아니라 메인 프로세스에서 돌아서, 창을 닫아도 계속 동작한다.

### 5.1 큰 흐름

```
[집중 타이머] --시간 다 됨--> [알림] --스트레칭--> [스트레칭 진행] --끝--> [집중 타이머 새로 시작]
      ^                         |--빠르게 2분 30초-> [스트레칭 진행(빠른 루틴)]
      |                         |--5분 뒤에-------> [집중 타이머 5분]
      |                         |--자리 비울게요--> [휴식(경과 시간)] --돌아왔어요--> [집중 타이머 새로 시작]
      |                         '--이번엔 건너뛰기-> [집중 타이머 새로 시작]
      '-- 컴퓨터를 5분 넘게 안 쓰면(유휴·화면 잠금) 쉰 걸로 보고, 돌아오는 순간 새로 시작
```

### 5.2 타이머 규칙

| 항목 | 규칙 |
| :-- | :-- |
| 집중 주기 | 기본 30분. 설정에서 15~90분 (5분 단위) |
| 시간 계산 | 1초씩 빼는 방식이 아니라 「끝나는 시각」을 저장하고 매번 현재 시각과 비교한다. 절전에서 깨어나도 어긋나지 않는다 |
| 미루기 | 「5분 뒤에」. 미루기 시간은 설정에서 3·5·10분 |
| 자리 비움 감지 | 키보드·마우스 입력이 유휴 기준(기본 5분, 설정 3~15분) 넘게 없으면 타이머를 멈춘다. 다시 입력이 들어오면 쉬고 온 것으로 보고 집중 타이머를 처음부터 시작한다. 화면 잠금·절전도 똑같이 처리한다 |
| 유휴 기준보다 짧게 자리를 비움 | 아무 일도 없던 것처럼 이어서 센다 |
| 수동 일시정지 | 「일시정지」는 풀 때까지 멈춘다. 「1시간 쉬기」는 1시간 뒤 저절로 다시 시작한다 |
| 근무 시간 | 기본은 켜짐, 평일 09:00~18:00. 출근·퇴근 시각과 요일을 설정에서 바꾼다. 퇴근이 출근보다 이르면 자정을 넘기는 근무로 본다 |
| 근무 시간 밖 | 「퇴근」 상태로 멈추고 알림을 보내지 않는다. 홈에 다음 출근 시각을 띄운다 |
| 출근 시각이 됨 | 집중 타이머를 새 주기로 시작한다 |
| 퇴근 시각이 됨 | 멈추고 「퇴근 시간이에요」 알림에 오늘 스트레칭 횟수를 담는다. 스트레칭·휴식 중이면 끝날 때까지 기다렸다가 멈춘다 |
| 근무 시간 밖에 「지금 시작」 | 다음 출근 시각까지는 근무 시간을 무시하고 돈다(야근용) |
| 알림이 떠 있는데 아무것도 안 누름 | 알림 상태로 그대로 둔다. 자리 비움 감지에 걸리면 돌아왔을 때 집중 타이머를 새로 시작한다 |

### 5.3 알림 방식

설정에서 고른다.

- **창 띄우기(기본)**: 앱 창을 앞으로 가져오고 OS 알림도 보낸다. 창은 선택할 때까지 항상 위에 둔다.
- **알림만**: OS 알림만 보낸다. 알림을 누르면 창이 열린다. 메뉴 막대·트레이 아이콘의 시간 표시가 「스트레칭!」으로 바뀐다.

알림음은 설정에서 끌 수 있다.

### 5.4 스트레칭 루틴

거북목·라운드숄더에 흔히 권하는 사무실용 동작으로 다시 짰다. 모든 동작은 의자에 앉거나 그 자리에서 선 채로 할 수 있다. 양쪽을 번갈아 하는 동작은 사진을 좌우 반전해서 반대쪽을 보여준다.

정적 스트레칭은 30초는 유지해야 효과가 있다고 보고, **동작마다 최소 30초**를 채운다. 양쪽을 하는 동작은 한쪽당 30초다.

**기본 루틴 (약 5분 30초)**

| # | 동작 | 하는 법 | 시간 |
| :-- | :-- | :-- | :-- |
| 1 | 어깨 돌리기 | 어깨를 귀까지 끌어올렸다가 뒤로 크게 돌려 내린다 | 30초 |
| 2 | 턱 당기기 | 시선은 정면 그대로, 턱을 수평으로 뒤로 밀어 넣는다. 고개를 숙이지 않는다 | 5초 유지 × 6회 (40초) |
| 3 | 옆목 늘리기 | 한 손은 의자를 잡아 어깨를 고정하고, 반대 손으로 머리를 옆으로 지그시 당긴다 | 오른쪽 30초 · 왼쪽 30초 |
| 4 | 뒷목 대각선 늘리기 | 고개를 45도 돌려 겨드랑이를 보듯 숙이고, 손을 뒤통수에 얹어 무게만 싣는다 | 오른쪽 30초 · 왼쪽 30초 |
| 5 | 가슴 열기 | 등 뒤로 깍지를 끼고 팔을 펴며 날개뼈를 모은다. 고개는 들지 않는다 | 30초 |
| 6 | 팔 바깥으로 벌리기 | 팔꿈치를 옆구리에 붙이고 직각으로 굽힌 채, 팔을 문 열듯 바깥으로 벌려 가슴을 편다(어깨 외회전) | 2초 × 10회 (38초) |
| 7 | 날개뼈 모으기 (W) | 팔을 W자로 만들고 팔꿈치를 아래·뒤로 당긴다 | 3초 조이기 × 8회 (31초) |
| 8 | 목 버티기 | 깍지 낀 손으로 뒤통수를 받치고, 머리는 움직이지 않은 채 뒤로 민다 | 5초 밀기 × 5회 (33초) |

**빠른 루틴 (약 2분 30초)**: 턱 당기기 6회 → 옆목 늘리기 양쪽 30초씩 → 팔 바깥으로 벌리기 10회.

진행 중 화면에는 사진, 동작 이름, 짧은 설명, 남은 초, 몇 번째 반복인지, 어느 쪽인지를 보여준다. 단계가 바뀌거나 반복을 할 때마다 짧은 소리를 낸다. 화면을 안 보고 따라 할 수 있게 하려는 것이다.

화면 아래에는 항상 「아프거나 저리면 바로 멈추세요」를 띄운다.

### 5.5 저장하는 것

모두 OS 사용자 데이터 폴더의 JSON 파일에 저장한다.

- 설정: 집중 주기, 미루기 시간, 유휴 기준, 근무 시간(켜기·출근·퇴근·요일), 기본 루틴, 알림 방식, 알림음, 로그인 시 자동 실행
- 오늘 통계: 스트레칭 완료, 빠른 루틴 완료, 건너뜀, 미룸, 자리 비움 횟수. 날짜가 바뀌면 새로 센다. 지난 날짜는 30일까지만 남긴다.

## 6. 화면

창은 하나(약 520×680)이고, 안에서 화면이 바뀐다. 닫기 버튼을 누르면 앱이 꺼지지 않고 숨는다. 완전히 끄려면 메뉴 막대·트레이 메뉴의 「종료」를 쓴다.

| 화면 | 보여주는 것 | 할 수 있는 것 |
| :-- | :-- | :-- |
| 홈 | 원형 진행 표시, 남은 시간, 상태 문구(집중 중·일시정지·자리 비움·퇴근), 오늘 통계 | 일시정지/재개(퇴근 상태면 지금 시작), 지금 스트레칭, 처음부터 다시, 설정 |
| 알림 | 「30분 지났어요」, 오늘 통계 | 스트레칭(기본) · 빠르게 · 5분 뒤에 · 자리 비울게요 · 이번엔 건너뛰기 |
| 스트레칭 | 사진, n/7단계, 동작 이름·설명, 남은 초, 반복 횟수, 좌·우 표시, 전체 진행 막대 | 이전 · 일시정지 · 다음 · 그만하기 |
| 완료 | 「잘했어요」, 다음 알림 시각 | 3초 뒤 홈으로 자동 이동 |
| 휴식 | 걷는 사진, 지난 시간(00:00부터) | 돌아왔어요 |
| 설정 | 5.5의 설정 항목 | 바로 적용. 집중 주기를 바꾸면 진행 중인 타이머는 새 주기로 다시 시작 |

**메뉴 막대·트레이**: 맥은 메뉴 막대 아이콘 옆에 남은 시간(`23:41`)을 띄우고, 윈도우는 마우스를 올리면 툴팁으로 보여준다. 메뉴: 남은 시간 · 일시정지/재개 · 지금 스트레칭 · 1시간 쉬기 · 창 열기 · 종료.

**상태별 처리**

| 상황 | 처리 |
| :-- | :-- |
| 첫 실행 | 근무 시간이면 바로 집중 타이머를 시작하고 홈을 보여준다. 1판처럼 「시작하기」를 따로 누르게 하지 않는다. 근무 시간 밖이면 퇴근 상태로 연다 |
| 근무 요일을 하나도 안 고름 | 퇴근 상태로 두고 「근무 요일이 없어요. 설정에서 골라 주세요」를 띄운다 |
| 통계 0회 | 「오늘 아직 스트레칭 안 했어요」 |
| 사진을 못 읽음 | 사진 자리에 동작 이름을 크게 띄운다. 진행은 계속된다 |
| 설정·통계 파일이 깨짐 | 기본값으로 시작하고 깨진 파일은 `.bak`으로 옮겨 둔다 |
| OS 알림 권한 없음 | 창 띄우기로 대신 알린다 |
| 스트레칭 중 화면 잠금 | 스트레칭을 일시정지한다. 돌아오면 이어서 할지 그만할지 고른다 |

## 7. 수용 기준

- **Given** 집중 주기가 30분이고 타이머가 돌고 있을 때, **When** 30분이 지나면, **Then** 창이 앞에 뜨고 OS 알림이 오며 메뉴 막대 표시가 「스트레칭!」으로 바뀐다.
- **Given** 알림 화면에서, **When** 「5분 뒤에」를 누르면, **Then** 5분짜리 타이머가 돌고 오늘 통계의 「미룸」이 1 늘어난다.
- **Given** 집중 타이머가 12분 남았을 때, **When** 6분 동안 입력이 없다가 다시 마우스를 움직이면, **Then** 타이머는 30:00부터 다시 시작하고 「자리 비움」이 1 늘어난다.
- **Given** 집중 타이머가 12분 남았을 때, **When** 2분 동안 입력이 없다가 다시 움직이면, **Then** 타이머는 멈추지 않고 10분 남은 상태로 이어진다.
- **Given** 기본 루틴 3단계(옆목 늘리기)에서, **When** 오른쪽 30초가 끝나면, **Then** 사진이 좌우 반전되고 「왼쪽」 표시로 30초가 다시 시작된다.
- **Given** 스트레칭 중, **When** 「그만하기」를 누르면, **Then** 홈으로 돌아가 집중 타이머가 새로 시작되고 완료 횟수는 늘지 않는다.
- **Given** 창을 닫은 상태에서, **When** 집중 시간이 끝나면, **Then** 창이 다시 나타난다(알림 방식이 「창 띄우기」일 때).
- **Given** 근무 시간이 평일 09:00~18:00일 때, **When** 수요일 18:00이 되면, **Then** 타이머가 멈추고 「퇴근 시간이에요」 알림이 오며, 홈에는 「내일 오전 9:00 출근 때 다시 시작해요」가 뜬다.
- **Given** 토요일에 앱을 켜면, **When** 홈을 보면, **Then** 퇴근 상태이고 다음 시작은 월요일 09:00이다.
- **Given** 퇴근 상태에서, **When** 「지금 시작」을 누르면, **Then** 타이머가 돌고, 다음 날 출근 시각부터는 다시 평소 규칙을 따른다.
- **Given** 맥과 윈도우에서, **When** 빌드한 앱을 설치해 실행하면, **Then** 둘 다 메뉴 막대·트레이에 아이콘이 생기고 위 동작이 똑같이 된다.

## 8. 기술 구성

| 영역 | 선택 | 이유 |
| :-- | :-- | :-- |
| 앱 | Electron | 맥·윈도우를 한 코드로 |
| 화면 | HTML·CSS·순수 JS(빌드 과정 없음) | 화면이 여섯 개뿐이라 프레임워크가 오히려 짐이다 |
| 타이머·상태 | 메인 프로세스의 상태 기계. 시계를 주입받는 순수 모듈로 분리 | 창이 없어도 돌아야 하고, 단위 테스트로 시간 규칙을 검증하려고 |
| 자리 비움 | `powerMonitor.getSystemIdleTime()`, `lock-screen`·`suspend` 이벤트 | 추가 권한 없이 맥·윈도우 모두 동작 |
| 배포 | electron-builder: 맥 `dmg`(universal), 윈도우 `nsis` 설치 파일(x64·arm64) | 빌드 이름은 영문 `ProtectNeck`. 한글로 두면 맥 헬퍼 앱 이름까지 한글이 되어 패키징한 앱이 시작하자마자 죽는다. 화면에 보이는 이름만 한글로 준다 |
| 사진 | 실사 사진 생성 후 1536px JPEG로 압축(장당 300KB 안팎) | |

## 9. 열린 질문

- 점심시간을 따로 뺄지. 지금은 자리 비움 감지로 충분하다고 보고 넣지 않았다.
- 전체 화면 앱(발표·영상 통화) 중에도 창을 띄울지. 지금은 띄운다. 회의가 잦으면 「전체 화면일 때는 알림만」 옵션을 검토한다.
- 기본 집중 주기 30분이 맞는지. 2주 써 보고 미룸 비율이 높으면 45분으로 바꾼다.
- 스트레칭 동작은 일반적인 사무실 스트레칭을 참고해 고른 것이고 전문가 검수를 받지 않았다. 목 디스크 등 질환이 있으면 맞지 않을 수 있다. `확인 필요`
